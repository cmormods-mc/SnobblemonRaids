CobbleRaids BWG Compatibility 1.0.0

Install this JAR alongside CobbleRaids 0.8.14 Phase 30 Core and
Oh The Biomes We've Gone 2.6.0 or newer.

This add-on extends CobbleRaids' 18 type-based biome tags with BWG biomes.
It contains no boss definitions and therefore cannot duplicate the 130-boss pool.
Removing this JAR safely returns every boss to its vanilla biome rules.
